# Seismic TravelTime Picker v0.3.0

Первый общедоступный тестовый выпуск для Windows.

## Возможности

- Просмотр исходных SEG-Y/SGY сейсмограмм и настройка отображения.
- Ручное пикирование максимумов и минимумов с проекцией на оси трасс.
- Предупреждения при возможном переходе на другую фазу.
- Полуавтоматическое прослеживание между опорными точками с ручным подтверждением.
- Расчёт времени прихода волны в миллисекундах, экспорт TXT/CSV.
- Сохранение и восстановление проекта.

## Запуск

Скачайте `SeismicTravelTimePicker.exe` из раздела **Assets** этого релиза и запустите в Windows 10/11. Python для запуска готового EXE не требуется.

**Важно:** рабочая версия для опытной эксплуатации; не аттестованное промышленное ПО. Проверяйте пики и времена перед использованием в интерпретации. Если Windows предупреждает о неизвестном издателе, убедитесь, что файл скачан с официальной страницы проекта. EXE пока не имеет цифровой подписи.
