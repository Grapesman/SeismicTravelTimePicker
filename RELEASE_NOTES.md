# SeisPeak — Seismic TravelTime Picker v0.4.0

Обновление интерфейса и многосейсмограммная обработка (Windows).

## Что нового

- Новое название **SeisPeak** и фирменная иконка Windows-приложения. Названия репозитория и EXE пока сохранены для совместимости.

- Выбор сразу нескольких SGY/SEG-Y через кнопку «Открыть SGY» (можно сотни файлов).
- Переключение файлов верхним списком и стрелками; точки, автоматические предложения,
  история исправлений, усиление и масштаб сохраняются отдельно для каждого файла.
- «Сохранить проект» при нескольких файлах создаёт единый JSON-сеанс для восстановления
  списка файлов и результатов после перезапуска (исходные SGY необходимо сохранить).
- Кнопки − и + около ползунка усиления, шаг 0,1; значение коэффициента показано рядом.
- Зум колёсиком мыши в точке курсора и выделение прямоугольника Shift + левая кнопка.
- Переключатель времени мс/мкс в правой таблице и окне результатов.
- Экспорт TXT/CSV **по-прежнему в миллисекундах** для совместимости с существующими расчётами.
- Исходные амплитуды и заголовки SEG-Y не изменяются.

## Установка

Скачайте `SeismicTravelTimePicker.exe` в Assets релиза и запустите в Windows 10/11.
Python устанавливать не требуется. Приложение не подписано цифровой подписью.

**Важно:** это тестовая версия для проверки пользователями, не аттестованное промышленное ПО.
Перед использованием в интерпретации проверяйте пики и время прихода волн.
