# SeisPeak v0.5.0

- Галочка «Предупреждать о скачке» на верхней панели включает или отключает всплывающее подтверждение при возможной смене фазы.
- «Общий TXT» сохраняет один файл с восемью столбцами по всем загруженным SGY, на которых есть подтверждённые пики.
- SRC_ID и координаты каждой строки читаются из соответствующего SGY. Неподтверждённые автоматические точки в TXT не включаются.
- Сохранены отдельные проекты, переключение SGY и остальные функции v0.4.
