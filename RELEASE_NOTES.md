# Pic Editor (PE) v0.6.0-beta.1

**Предварительная версия для тестирования, не финальный Windows-релиз.**

- Название **Pic Editor (PE)**, новая иконка и заставка.
- Масштабирование колёсиком по двум осям, отдельно по Y (`Shift`) и X (`Ctrl`); перетаскивание графика с зажатой ЛКМ на пустом месте; стандартная панель Matplotlib удалена.
- Сворачиваемый блок настроек пикирования и встроенный годограф справа; полноразмерная вторая вкладка.
- Годограф всех открытых SGY и типов волн; выбор и перенос точек синхронизированы с сейсмограммой.
- Несколько типов волн на одном приёмнике: название, буквенно-цифровой код Wave, цвета линии, пиков и проекций.
- Автоматическая интерполяция между ручными опорами с ручным подтверждением предложений.
- Импорт TXT+SGY с полной валидацией идентификаторов, координат, геометрии и дискретизации.
- Общий TXT и TXT одной сейсмограммы экспортируют все подтверждённые типы волн.
- Модель сохранения `schema_version: 3`, поддержка старых многосейсмограммных сеансов v0.5.
- Всплывающие подсказки к управляющим кнопкам.

**Ограничения:** построение годографов и разделение встречных/нагоняющих по геометрии не заменяет экспертную интерпретацию; программа не извлекает несуществующие вступления. Для промышленного выпуска необходимы отдельные испытания на Windows и разноплановых SEG-Y.
