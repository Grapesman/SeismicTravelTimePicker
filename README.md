# Pic Editor (PE) — пикирование сейсмических волн

**Версия 0.6.0-beta.1** — предварительная версия настольной программы для чтения SEG-Y/SGY, ручного и полуавтоматического пикирования, построения годографов и экспорта времён прихода в TXT/CSV.

> Это тестовая версия. Перед использованием результатов в геофизической интерпретации необходима проверка оператором. Исходные SGY не изменяются.

## Готовая Windows-программа

После публикации проверенного EXE на странице [GitHub Releases](https://github.com/Grapesman/SeismicTravelTimePicker/releases) скачайте файл **`PicEditor.exe`** из раздела **Assets** и запустите в Windows 10/11. Python пользователю EXE не требуется. До появления этого файла в разделе Releases новая версия ещё не опубликована.

## Как пользоваться

1. **Загрузите данные.** Нажмите **«Открыть SGY»** и выберите один или несколько `.sgy`/`.segy`. Для переключения пользуйтесь стрелками **◀ ▶** и выпадающим списком сейсмограмм. Через меню **«Файл»** доступна загрузка папки.
2. **Настройте масштаб.** Колесо мыши увеличивает область по X и Y, **Shift + колесо** — только по времени (Y), **Ctrl + колесо** — только по расстоянию (X). Удерживайте **левую кнопку на пустом месте** и перетаскивайте график. **Shift + ЛКМ с протягиванием** выделяет область для увеличения. **«Сброс масштаба»** возвращает полный вид.
3. **Выберите волну.** В поле **«Волна»** по умолчанию активна `0 · Головная волна`. Кнопка **«+ Волна»** создаёт другую волну с собственным **кодом Wave**, названием и цветами. Кнопка **«Палитра»** изменяет цвета линии, вершин пиков и горизонтальных проекций. На одном приёмнике можно отметить несколько разных волн, переключаясь между ними.
4. **Ставьте пики.** Нажимайте на нужные экстремумы сейсмических трасс. Линия и точки выбранной волны отображаются её цветами. **«⚙ Настройки пикирования»** открывает настройки полярности, поиска и контроля фазы. Отмеченные пики можно перетаскивать; правый клик удаляет точку. **«Отменить»** отменяет последнее действие.
5. **Интерполируйте при необходимости.** В настройках **«Автофаза»** включите **«Автоинтерполяция между опорами»**, чтобы программа предлагала промежуточные экстремумы после ручной постановки опорных пиков. Предложения **не попадают в TXT**, пока не нажата кнопка **«Подтвердить предложенные точки»**. Можно также запускать **«Проследить фазу»** вручную.
6. **Работайте с годографом.** Справа находится общий график времён прихода всех уже пропикированных SGY и всех волн. Нажмите **«Развернуть годограф»** для перехода на вторую вкладку. Клик по точке на годографе выбирает соответствующий SGY и пик; перетаскивание точки вверх/вниз корректирует ближайший экстремум соответствующей сейсмической трассы. Изменение сразу отражается на обоих графиках.
7. **Сохраните результаты.** **«Рассчитать и показать таблицу»** отображает времена прихода. **«Экспорт TXT»** выгружает все подтверждённые волны текущего SGY, **«Общий TXT»** — все подтверждённые пики всех SGY в одном файле. **«Сохранить проект»** сохраняет все SGY, волны, отметки и настройки в `.stp-session.json`, чтобы продолжить работу позднее.
8. **Восстановите пики из TXT.** Нажмите **«Импорт TXT»**, выберите TXT/CSV, затем все соответствующие SGY. Программа проверит источники, приёмники, координаты, единицы и время отсчётов. Если файл отсутствует, идентификаторы неоднозначны или время не соответствует сигналу, импорт отменяется с сообщением о проблеме. После проверки пользователь подтверждает добавление точек.

При наведении мыши на элементы управления появляются подсказки.

## Формат экспорта

```text
SRC_ID  SRC_X  SRC_Z  RCV_ID  RCV_X  RCV_Z  Traveltime  Wave
```

Время `Traveltime` хранится **в миллисекундах**, независимо от переключателя мс/мкс в интерфейсе. Значения идентификаторов и координат берутся из заголовков SGY. `SRC_Z` и `RCV_Z` по принятому формату равны 0. Поле `Wave` содержит введённый цифровой или буквенный код, например `0`, `P`, `R`.

Встречные и нагоняющие пары годографов выделяются **по геометрии источников и общему участку приёмников**. Если она неоднозначна, автоматической классификации нет. Само пикирование не является доказательством правильной интерпретации волны.

## Запуск из исходников (для разработчика)

Python 3.11–3.12 с Tkinter:

```bash
python -m pip install -r requirements.txt
python main.py
```

Для Windows EXE предусмотрена сборка через `.github/workflows/windows.yml`, но данная бета-сборка пока не проверена на Windows. Старые проекты v0.5 (`schema_version: 2`) загружаются в новую модель; новый сеанс сохраняется как `schema_version: 3`.
