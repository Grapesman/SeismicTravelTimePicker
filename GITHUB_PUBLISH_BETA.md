# Публикация тестовой версии PE v0.6.0-beta.1 через сайт GitHub

**Важно:** это тестовая версия. Сначала проверьте программу на своих сейсмограммах и Windows через Parallels. Не заменяйте стабильную `v0.5.0` неподтверждённой сборкой.

1. Скачайте ZIP, распакуйте, откройте папку `SeismicTravelTimePicker`. Репозиторий: `https://github.com/Grapesman/SeismicTravelTimePicker` (проверьте имя).
2. На GitHub откройте **Code → Add file → Upload files** и перетащите **содержимое** папки проекта, не саму внешнюю папку. Старые имена файла EXE не сохраняются — новая программа будет называться **PicEditor.exe**.
3. Сделайте коммит с названием `Beta v0.6.0 - Pic Editor redesign`.
4. Обновите скрытый файл `.github/workflows/windows.yml` отдельно через веб-редактор GitHub: откройте его, нажмите карандаш, замените текст содержимым одноимённого файла из архива, затем **Commit changes**.
5. Проверьте **Actions → Windows EXE — Build and Release**, дождитесь успешной тестовой сборки. Скачайте артефакт **PicEditor-Windows** для проверки в Windows. Для тестового релиза включите **Run workflow → Publish or update v0.6.0-beta.1… → Run workflow**. GitHub создаст **prerelease**, не заменяя `v0.5.0`.
6. В **Releases → v0.6.0-beta.1 → Assets** появится `PicEditor.exe`, если сборка и публикация пройдут успешно.

Вкладка **Actions** проверяет код и сборку, но не подтверждает корректность геофизической интерпретации. Для стабильного релиза отдельно проверьте импорт TXT с несколькими SGY, многоволновое пикирование и взаимную корректировку точек на годографе и сейсмограмме.
